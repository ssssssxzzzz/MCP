# Account prep pack

1. `get_watchlist` — note if they are customer-done, priority, or competitor-adjacent.
2. `search_companies` for ZoomInfo company id (free).
3. Free: recent `search_scoops` on that company/industry; optional `find_similar_companies` if useful.
4. Free: `search_contacts` for Facilities, Validation, Sterility/Micro, QA, EHS, Ops — titles only, **no redeem**.
5. Only if user says go deep: `account_research` (AI credits) — label the burn in the reply.
6. Reply shape:
   - What they are / site footprint
   - Why now (shutdown, expansion, move, biologicals)
   - Win theme vs Curis/TOMI (response time / pricing / validated AHP)
   - 3 people to open (title + why)
   - Suggested next step (MSA vs one-off shutdown)
